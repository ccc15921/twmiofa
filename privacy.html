「ミオファ的高麗菜園」（以下稱「本站」，網址 https://ccc15921.github.io/twmiofa/）是由大神ミオ的粉絲（ミオファ）個人製作的非官方粉絲網站，與 COVER 株式会社及 hololive production 無關。本政策說明本站如何收集、使用與保護你的資料。

1. 不登入也能使用

不登入時，你的繳稅紀錄只會儲存在你自己裝置的瀏覽器（localStorage）中，不會傳送到任何伺服器。

2. 與「開拓者の愉悅部」共用帳號

本站與同一位製作者的 AZKi 粉絲網站「開拓者の愉悅部」使用同一套登入與雲端資料庫。在任一站登入，另一站也會是登入狀態；你的個人設定（暱稱、頭像、是否計入統計等）兩站共用。兩站的紀錄分開儲存、互不混用。

3. 使用 Google 帳號登入時收集的資料

  • Google 帳號的電子郵件地址（用於識別你的帳號，不會公開）
  • Google 帳號的名稱與頭像網址（僅用於登入後在你自己的畫面上顯示，不會公開）
  • 帳號建立與最後登入的時間

4. 你在本站產生的資料

  • 周邊繳稅紀錄（項目代號、數量、更新時間）

5. 資料的使用目的

  • 讓你在不同裝置之間同步自己的紀錄

本站不會出售你的資料，也不會用於廣告。目前本站不顯示任何統計或排行；之後若新增購買人數統計或排行榜等功能，會先更新本政策。

6. 資料的儲存

登入後的資料儲存在本站使用的雲端資料庫服務 Supabase 上，並設定為每個人只能讀寫自己的紀錄。網站本身由 GitHub Pages 提供。這些服務可能位於台灣以外的地區。

7. 刪除你的資料

你可以隨時登出，登出後紀錄仍保留在該裝置的瀏覽器中。若要刪除雲端上的所有資料，可使用網站上的刪除帳號功能，或透過下方聯絡方式提出。因為帳號與「開拓者の愉悅部」共用，刪除帳號會同時刪除兩站雲端上的所有資料。清除瀏覽器的網站資料即可刪除儲存在你裝置上的紀錄。

8. Google 使用者資料

本站對於從 Google API 取得之資料的使用與轉移，遵守 Google API 服務使用者資料政策，包括其中的「有限使用」規定。

9. 政策變更

本政策若有變更，會更新於本頁並修改上方的日期。重大變更時會在網站上公告。

10. 聯絡方式

對本政策或你的資料有任何疑問，請透過 GitHub Issues 與我們聯絡。

3. Google アカウントでログインした場合に取得する情報

  • Google アカウントのメールアドレス（アカウントの識別に使用し、公開しません）
  • Google アカウントの名前とプロフィール画像の URL（ログイン後のご自身の画面にのみ表示し、公開しません）

4. 本サイトで作成される情報

  • グッズの納税記録（項目コード、数量、更新日時）

5. 利用目的

  • 複数の端末間でご自身の記録を同期するため

情報を販売したり、広告に利用したりすることはありません。現在、本サイトでは統計やランキングを表示していません。今後、購入人数の統計やランキングなどの機能を追加する場合は、事前に本ポリシーを更新します。

6. 情報の保存

ログイン後のデータはクラウドデータベースサービス Supabase に保存され、各ユーザーは自分の記録のみ読み書きできるよう設定しています。サイト自体は GitHub Pages で公開しています。これらのサービスは日本・台湾以外の地域にある場合があります。

7. 情報の削除

いつでもログアウトでき、ログアウト後も記録はその端末のブラウザに残ります。クラウド上のすべてのデータを削除したい場合は、サイト上のアカウント削除機能を使うか、下記の連絡先からご依頼ください。アカウントは「開拓者の愉悦部」と共通のため、アカウントを削除すると両サイトのクラウド上のデータがすべて削除されます。端末に保存された記録は、ブラウザのサイトデータを消去することで削除できます。

本サイトによる Google API から取得した情報の使用および転送は、Google API サービスのユーザーデータに関するポリシー（「限定的使用」の要件を含む）に従います。

本ポリシーを変更する場合は、本ページを更新し上記の日付を改めます。重要な変更はサイト上でお知らせします。
